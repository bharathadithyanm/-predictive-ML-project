# Predictive Modeling Using Machine Learning

## 📌 Project Overview
This project builds a machine learning model to predict outcomes using supervised learning techniques.

## ⚙️ Algorithms Used
- Linear Regression
- Decision Tree
- Random Forest

## 📊 Features
- Train and test model
- Accuracy comparison
- Confusion Matrix visualization
- ROC Curve analysis

## 🚀 How to Run

```bash
pip install -r requirements.txt
python main.py
